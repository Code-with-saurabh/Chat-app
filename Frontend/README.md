 # Real-Time Chat Application
 A full-stack real-time chat application where users can search other users,
 send messages, and store conversations securely.

 ## ✨ Features

- User Authentication
- User Search
- One-to-One Chat
- Persistent Message Storage
- Responsive UI
- Secure Backend APIs

## 🛠 Tech Stack

Frontend
- React
- Tailwind CSS

Backend
- Node.js
- Express.js

Database
- MongoDB

Authentication
- JWT

Others
- Axios
